# แบบฝึกหัดที่ 17 — Vue.js

ผู้จัดทำ: **Chatree Puangpacung · 69702075**

## วิธีเปิดโปรแกรม

ต้องมี Node.js 22.12 ขึ้นไป จากนั้นเปิด Terminal ในโฟลเดอร์นี้:

```sh
npm install
npm run dev
```

เปิด URL ที่ Terminal แสดง (ปกติ http://127.0.0.1:5173)

## งานตามโจทย์

- แสดงสินค้าแบบคอลัมน์ด้วย CSS Grid และ `v-for`
- แสดงสินค้าแบบตาราง
- แสดงข้อมูลผู้ใช้แบบตาราง
- ดึงข้อมูลจริงด้วย `fetch` เมื่อ component เริ่มทำงาน (`onMounted`)
- ค้นหาในข้อมูล 30 รายการที่โหลดมา และรีเฟรชข้อมูลได้
- แสดงสถานะโหลด ข้อผิดพลาด และผลการค้นหาว่าง

API: https://dummyjson.com/products?limit=30 และ https://dummyjson.com/users?limit=30

ราคาใช้ USD ตามข้อมูล API ข้อมูลผู้ใช้เป็นข้อมูลตัวอย่างจาก DummyJSON ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อดึงข้อมูล

ไม่มี VDO บทเรียนที่ 11 แนบมา โปรแกรมจึงทำตามข้อกำหนดในโจทย์ ไม่ได้รับรองว่าโค้ดตรงกับ VDO

สร้างไฟล์สำหรับส่งหรือเผยแพร่ด้วย `npm run build` ผลลัพธ์อยู่ใน `dist/` สามารถตรวจด้วย `npm run preview`
